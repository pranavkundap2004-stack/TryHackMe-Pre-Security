# 🧠 Core Concepts

## CIA Triad

| Principle | Purpose |
|-----------|----------|
| Confidentiality | Protect information from unauthorized access |
| Integrity | Ensure information remains accurate and unmodified |
| Availability | Ensure systems and data remain accessible when needed |

---

## Encryption Process

```
Plaintext
     │
Encryption
     │
     ▼
Ciphertext
     │
Decryption
     │
     ▼
Plaintext
```

Encryption protects sensitive information during storage and transmission.
