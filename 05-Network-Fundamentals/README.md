# 🧠 Core Concepts

## OSI Model

| Layer | Name | Purpose |
|--------|------|----------|
| 7 | Application | User-facing network services |
| 6 | Presentation | Data formatting and encryption |
| 5 | Session | Manages communication sessions |
| 4 | Transport | Reliable data delivery |
| 3 | Network | Routing using IP addresses |
| 2 | Data Link | Frames and MAC addresses |
| 1 | Physical | Physical transmission of data |

---

## Packet vs Frame

| Packet | Frame |
|---------|-------|
| Operates at the Network Layer | Operates at the Data Link Layer |
| Uses IP Addresses | Uses MAC Addresses |
| Routed between networks | Delivered within local networks |

# 💻 Practical Knowledge

## Basic Networking Commands

```bash
ping
ipconfig
ifconfig
traceroute
nslookup
netstat
```

These commands are commonly used to test connectivity, inspect network configurations, troubleshoot communication issues, and gather network information.

---

## Example

```bash
ping google.com
```

Checks whether a remote host is reachable over the network.
