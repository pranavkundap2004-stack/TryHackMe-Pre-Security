# 📖 Overview

The **Software Basics** module introduces the essential concepts behind how computers store, process, and manipulate data. It provides a beginner-friendly introduction to data representation, character encoding, programming fundamentals, and relational databases.

Understanding these concepts is important in cybersecurity because attackers and defenders both rely on software, programming logic, and data handling. This module establishes the software foundation required before exploring web security, scripting, and security automation.

# 💻 Practical Knowledge

## 🔢 Number Systems

```
Binary        → Base 2
Decimal       → Base 10
Hexadecimal   → Base 16
```

Understanding different number systems is important because computers store information in binary while hexadecimal provides a compact and human-readable representation commonly used in computing and cybersecurity.

---

## 🔤 Character Encoding

- ASCII
- Unicode
- UTF-8
- UTF-16
- UTF-32
- ISO/IEC 8859 Series

These encoding standards allow computers to correctly store, exchange, and display text across different operating systems and languages.
