The **Operating Systems Basics** module introduces the core concepts of modern operating systems and explains how users interact with Windows and Linux environments. It also provides an introduction to command-line interfaces and basic operating system security concepts.

Understanding operating systems is a fundamental skill for cybersecurity professionals because nearly every security assessment, investigation, or defensive activity involves interacting with Windows or Linux systems.

# 💻 Practical Knowledge

## Essential Linux Commands

```bash
pwd
ls
cd
mkdir
touch
cp
mv
rm
cat
nano
chmod
```

These commands are commonly used to navigate directories, manage files, edit text files, and configure permissions in Linux systems.

---

## Basic Windows Commands

```cmd
dir
cd
ipconfig
whoami
hostname
systeminfo
tasklist
```

These commands help navigate the file system, identify the current user, gather system information, and inspect running processes.
